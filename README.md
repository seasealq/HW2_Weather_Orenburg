# ДЗ2 — Прогнозирование осадков в Оренбурге

Курс: машинное обучение, 4 курс. Город: Оренбург, Россия.

Дневные данные Open-Meteo Historical Weather API за 01.01.2020–31.12.2025 (2 192 наблюдения) преобразованы в бинарный признак: осадки есть, если суточная сумма больше 0 мм. Данные разделены хронологически на train, validation и test. Сравниваются ARIMA(2,0,2), LSTM с 32 нейронами, простая модель Persistence (класс предыдущего дня) и baseline наиболее частого класса train.

## Запуск

Требуется Python 3.11. В каталоге проекта выполните:

```bash
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements_hw2.txt
jupyter notebook HW2_Weather.ipynb
```

Ноутбук читает `orenburg_weather_2020_2025.csv` из того же каталога. Обучение использует фиксированный seed; тестовая оценка выполняется в режиме one-step-ahead.

## Итоговые метрики

| Модель | Accuracy | F1 |
|---|---:|---:|
| Baseline | 0.5216 | 0.0000 |
| Persistence | 0.6697 | 0.6539 |
| ARIMA | 0.6697 | 0.6539 |
| LSTM | 0.6697 | 0.6539 |

На тестовой выборке ARIMA и LSTM дали те же бинарные прогнозы, что и Persistence, и не превзошли эту модель. Это результат сравнения на общих тестовых датах, а не ошибка расчёта.

## Дополнительное задание: Feature Engineering

В ноутбуке `HW2_Weather_Feature_Engineering.ipynb` сохраняется бинарный прогноз наличия осадков на следующий день. Добавлены календарные признаки даты и 20 лагов категории осадков; текущая категория `precip_category(t)` и сумма осадков `precipitation_sum(t)` в признаки не входят. Ряд ежедневный, поэтому лаг 1 соответствует предыдущему дню.

Категории суточной суммы (мм): 0 — ровно 0; 1 — `(0; 2.5]`; 2 — `(2.5; 7.5]`; 3 — `>7.5`. На полном исходном ряде частоты категорий составили 1220, 638, 243 и 91 день соответственно. Пороговые значения фиксированы до оценки моделей.

Новый табличный эксперимент — логистическая регрессия с L2-регуляризацией; параметр регуляризации выбран по validation. Тестовый период совпадает с основным ДЗ2 (439 дней, 19.10.2024–31.12.2025). Исходные значения: ARIMA(2,0,2) и LSTM(32) — Accuracy 0.6697, F1 0.6539; Persistence — те же значения. Новая модель получила Accuracy 0.6241, Precision 0.6510, Recall 0.4619, F1 0.5404, ROC-AUC 0.6854. По Accuracy и F1 улучшения нет; ROC-AUC выше, но итоговый вывод об улучшении качества по основным пороговым метрикам не делается.
